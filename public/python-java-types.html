📖 Теоретический материал

1. Что такое тип данных?

Тип данных — это множество значений и набор операций, которые можно над ними выполнять. Тип определяет, сколько памяти занимает переменная и как интерпретируются хранящиеся в ней биты.

2. Статическая и динамическая типизация

Java — язык со статической типизацией: тип переменной объявляется при её создании и не меняется в течение жизни программы.

int age = 20;        // переменная age всегда целое число
age = "двадцать";    // ❌ ОШИБКА компиляции!

Python — язык с динамической типизацией: тип определяется значением и может меняться.

age = 20            # age — int
age = "двадцать"    # теперь age — str (всё работает!)

4. Приведение типов

Явное приведение (программист сам указывает):

# Python
x = "42"
y = int(x)       # str → int
z = float("3.14") # str → float
// Java
String s = "42";
int y = Integer.parseInt(s);      // String → int
double z = Double.parseDouble("3.14");

Неявное приведение (автоматическое, безопасное):

int a = 5;
double b = a;  // int автоматически → double (5.0)

5. Особенности деления

# Python 3
print(10 / 3)   # 3.3333... (float)
print(10 // 3)  # 3 (целочисленное деление)
// Java
System.out.println(10 / 3);     // 3 (int / int = int)
System.out.println(10.0 / 3);   // 3.333... (double)

6. Коллекции данных

Выбор коллекции зависит от задачи:

  • Список (list/ArrayList) — упорядоченная изменяемая коллекция, допускает дубликаты.
  • Множество (set/HashSet) — неупорядоченная коллекция уникальных элементов.
  • Словарь (dict/HashMap) — пары «ключ → значение».
  • Кортеж (Tuple) — неизменяемый список (только в Python).
