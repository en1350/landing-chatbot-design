Теоретический материал

Структуры данных — способы организации и хранения данных в памяти компьютера для эффективного доступа и модификации.

📋 Линейные списки

Список (linked list) — динамическая структура данных, состоящая из узлов, каждый из которых содержит данные и ссылку на следующий узел.

Виды списков:

  • Односвязный список — каждый узел ссылается только на следующий
  • Двусвязный список — узлы ссылаются на следующий и предыдущий
  • Циклический список — последний узел ссылается на первый

🕸️ Графы

Граф — структура данных, состоящая из вершин (nodes) и рёбер (edges), соединяющих пары вершин.

Типы графов:

  • Ориентированный — рёбра имеют направление
  • Неориентированный — рёбра без направления
  • Взвешенный — рёбра имеют вес (стоимость)
  • Дерево — связный граф без циклов

🌳 Деревья

Дерево — иерархическая структура данных с корневой вершиной и связями "родитель-потомок".

Основные понятия:

  • Корень (root) — верхняя вершина
  • Лист (leaf) — вершина без потомков
  • Глубина — расстояние от корня до вершины
  • Высота — максимальная глубина

Виды деревьев:

  • Бинарное дерево — каждый узел имеет не более 2 потомков
  • Бинарное дерево поиска (BST) — левый потомок < родитель < правый

Обход деревьев: Прямой (корень→лево→право), Центральный (лево→корень→право), Обратный (лево→право→корень), В ширину (BFS).
