📖 Теория: Анализ данных с помощью ИИ

1. Что такое анализ данных?

Анализ данных — это процесс исследования, очистки, преобразования и моделирования данных с целью обнаружения полезной информации, принятия решений и получения выводов.

Современный анализ данных невозможен без методов искусственного интеллекта (ИИ) и машинного обучения (МО), которые позволяют обрабатывать огромные объёмы информации и находить скрытые закономерности.

2. Типы данных

  • Числовые (количественные): возраст, цена, температура — можно измерить и сравнить.
  • Категориальные (качественные): цвет, город, категория товара — описывают признак.
  • Текстовые: отзывы, статьи, сообщения — обрабатываются методами NLP.
  • Временные ряды: данные, упорядоченные по времени (курсы валют, продажи).

3. Этапы анализа данных

  • Сбор данных — получение информации из источников (БД, API, файлы).
  • Очистка данных — удаление дубликатов, пропусков, выбросов.
  • Исследовательский анализ (EDA) — визуализация и статистика.
  • Подготовка признаков (Feature Engineering) — создание переменных для модели.
  • Построение модели — выбор алгоритма ИИ и обучение.
  • Оценка и интерпретация — проверка качества и выводы.

4. Основные алгоритмы ИИ для анализа данных

  • Линейная регрессия — предсказание числового значения (цена, спрос).
  • Логистическая регрессия — бинарная классификация (спам/не спам).
  • Деревья решений и Random Forest — классификация и регрессия.
  • K-means кластеризация — группировка похожих объектов.
  • Нейронные сети — сложные задачи: распознавание образов, NLP.

5. Метрики качества моделей

  • Accuracy (точность) — доля правильных ответов среди всех.
  • Precision (полнота по положительным) — насколько модель точна в предсказаниях "да".
  • Recall (чувствительность) — какую долю реальных "да" нашла модель.
  • F1-score — гармоническое среднее Precision и Recall.

6. Визуализация данных

  • Гистограмма — распределение числовых данных.
  • Диаграмма рассеяния (scatter plot) — связь двух переменных.
  • Box plot — статистика и выбросы.
  • Heatmap — корреляционная матрица.
