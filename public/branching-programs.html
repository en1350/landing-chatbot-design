📖 Теоретический материал

1. Что такое разветвляющая структура?

Разветвляющий алгоритм — это алгоритм, в котором выбор направления выполнения зависит от результата проверки условия. В программировании такие структуры реализуются с помощью условных операторов.

Основные формы записи:

  • Полная форма: если условие истинно — выполняется одна группа действий, иначе — другая.
  • Краткая форма: действия выполняются только при истинности условия.
  • Вложенные условия: одно условие находится внутри другого.
  • Множественный выбор: несколько альтернативных веток (elif / else if).

2. Операторы сравнения и логические операторы

Операторы сравнения: == (равно), != (не равно), >, <, >=, <=

Логические операторы:

  • and (Python) / && (JS) — логическое И
  • or (Python) / || (JS) — логическое ИЛИ
  • not (Python) / ! (JS) — логическое НЕ

3. Синтаксис условных операторов

# Полная форма if условие: действия else: другие_действия # Множественный выбор if x > 0: print("Положительное") elif x < 0: print("Отрицательное") else: print("Ноль")
// Полная форма if (условие) { действия; } else { другие_действия; } // Множественный выбор if (x > 0) { console.log("Положительное"); } else if (x < 0) { console.log("Отрицательное"); } else { console.log("Ноль"); }

4. Тернарный оператор (сокращённая запись)

результат = значение1 if условие else значение2 # Пример: status = "совершеннолетний" if age >= 18 else "несовершеннолетний"
результат = условие ? значение1 : значение2; // Пример: let status = age >= 18 ? "совершеннолетний" : "несовершеннолетний";

5. Типичные ошибки

  • В Python — использование = вместо == для сравнения.
  • В Python — отсутствие двоеточия : после условия.
  • В JavaScript — сравнение == вместо строгого ===.
  • Неправильное использование логических операторов (забывание скобок вокруг сложных условий).
  • Путаница между and/or (Python) и &&/|| (JS).
