📚 Что такое база данных?

База данных (БД) — организованная совокупность данных, хранящихся в памяти компьютера и отражающая реальную предметную область.

🎯 Назначение БД

  • Хранение больших объёмов структурированной информации
  • Быстрый поиск и выборка нужных данных
  • Изменение и обновление информации
  • Защита данных от несанкционированного доступа
  • Совместный доступ нескольких пользователей

💡 Примеры применения

  • 🏫 Электронный журнал школы
  • 🏥 Медицинская карта пациента
  • 🛒 Каталог интернет-магазина
  • 📚 Библиотечный каталог
  • 🏦 Банковская система счетов
💡 Главное отличие БД от простого списка — структурированность и возможность эффективного поиска.

📊 Виды баз данных

БД классифицируют по способу организации данных. Нажмите на карточку, чтобы узнать подробнее.

🌳 Иерархическая
Данные организованы в виде «дерева»: один корневой элемент, от него отходят «ветви».
📁 Пример: файловая система (папка → подпапка → файл).
🕸️ Сетевая
Элементы могут иметь несколько «родителей». Сложная структура связей.
📁 Пример: социальные связи (человек — член нескольких групп).
📋 Реляционная
Данные хранятся в виде таблиц, связанных между собой. Самая распространённая модель!
📁 Пример: MySQL, PostgreSQL, MS Access, SQLite.
🧩 Объектно-ориентированная
Данные — как объекты со свойствами и методами.
📁 Пример: ObjectDB, db4o.
📦 NoSQL
Документо-ориентированные, ключ-значение, графовые БД. Гибкая структура.
📁 Пример: MongoDB, Redis, Cassandra.
💡 В школе изучают именно реляционные базы данных.

📋 Реляционная модель данных

Реляционная модель (от лат. relatio — отношение) — основа современных БД. Данные хранятся в таблицах (отношениях).

Основные понятия

  • Таблица (отношение) — структура данных с колонками и строками
  • Поле (атрибут, столбец) — свойство объекта
  • Запись (кортеж, строка) — один объект
  • Первичный ключ (PK) — уникальное поле для идентификации записи
  • Внешний ключ (FK) — поле, ссылающееся на PK другой таблицы
💡 PK должен быть уникальным и непустым. FK обеспечивает связь между таблицами.

🔢 Типы данных в БД

Каждое поле таблицы имеет тип данных:

  • INTEGER — целое число (1, 42, -7)
  • REAL / FLOAT — дробное число (3.14, 4.5)
  • TEXT / VARCHAR — текст («Иванов», «Москва»)
  • DATE — дата (2026-09-19)
  • TIME — время (14:30:00)
  • DATETIME — дата и время
  • BOOLEAN — логическое (TRUE / FALSE)
  • BLOB — двоичные данные (картинки, файлы)
💡 Правильный выбор типа — залог корректной работы БД и экономии памяти.

💬 Язык SQL: запросы к БД

Для работы с реляционными БД используется язык SQL (Structured Query Language). Вот примеры запросов к нашей БД «Библиотека»:

SELECT
SELECT fio, phone FROM Readers WHERE reg_date > '2025-01-01';

→ Выбрать всех читателей, зарегистрированных после 1 января 2025.

JOIN
SELECT R.fio, B.title, L.loan_date FROM Loans L JOIN Readers R ON L.reader_id = R.id JOIN Books B ON L.book_id = B.id;

→ Кто какую книгу брал и когда. Используется связь через таблицу Loans.

💡 JOIN — ключевое слово, которое объединяет таблицы по связям (FK → PK).

🛠️ Этапы создания базы данных

  1. Планирование — определение цели и предметной области
  2. Проектирование — структура: таблицы, поля, типы, связи
  3. Моделирование — инфологическая и даталогическая модели
  4. Реализация — создание БД в СУБД
  5. Наполнение — ввод реальных данных
  6. Тестирование — проверка запросов
  7. Эксплуатация — использование и резервное копирование

🔑 Ключевые термины

  • СУБД — программа для работы с БД (MS Access, MySQL, PostgreSQL)
  • SQL — язык запросов
  • Запрос — команда на выборку/изменение данных
