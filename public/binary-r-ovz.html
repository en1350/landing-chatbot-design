📘 Алгоритм построения числа R

Интерактивный урок с симулятором для учащихся с ОВЗ

📌 Условие задачи

На вход алгоритма подаётся натуральное число N. Алгоритм строит новое число R:

Шаг 1. Строится двоичная запись числа N.
Шаг 2. Считаем сумму цифр двоичной записи (то есть количество единиц).
Шаг 3а. Если сумма чётная:
→ дописываем справа 0,
→ два левых разряда заменяем на 10.
Шаг 3б. Если сумма нечётная:
→ дописываем справа 1,
→ два левых разряда заменяем на 11.
Шаг 4. Полученная двоичная запись переводится в десятичную систему — это и есть R.

Вопрос: укажите максимальное N, при котором R ≤ 19.

🔎 Разбор примеров из условия

Пример 1: N = 6

Двоичная запись: 110

Сумма цифр: 1+1+0 = 2 (чётная)

Дописываем 0: 1100

Заменяем два левых на 10: 1000

R = 1000₂ = 8 ✓

Пример 2: N = 4

Двоичная запись: 100

Сумма цифр: 1+0+0 = 1 (нечётная)

Дописываем 1: 1001

Заменяем два левых на 11: 1101

R = 1101₂ = 13 ✓

📊 Решение задачи: перебор значений

Нам нужно найти максимальное N, при котором R ≤ 19. Перебираем N и смотрим результат:

NN (двоич.)СуммаЧётность+битЗаменаR (двоич.)RR ≤ 19?

Анализ: при N ≥ 16 (5 бит) результат всегда ≥ 32, то есть больше 19. Значит, ищем среди N от 1 до 15.

Среди подходящих (R ≤ 19) максимальное значение — N = 12.

✅ Ответ: 12

💡 Подсказки и пояснения

Двоичная система — это запись числа с помощью цифр 0 и 1. Например, 6₁₀ = 110₂.
Сумма цифр в двоичной записи — это просто количество единиц. Для 110₂ это 1+1+0 = 2.
Чётное/нечётное: число делится на 2 без остатка → чётное, иначе → нечётное.
Два левых разряда — это две самые первые цифры слева в двоичной записи.
Перевод из двоичной в десятичную: 1000₂ = 1·8 + 0·4 + 0·2 + 0·1 = 8.
