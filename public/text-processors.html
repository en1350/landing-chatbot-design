🖥️ Что такое текстовый процессор?

Текстовый процессор — это прикладное программное обеспечение для создания, редактирования, форматирования и вывода на печать текстовой информации.

Примеры: MS Word, LibreOffice Writer, Google Docs, Apple Pages, WordPad.

💡 Важно: Текстовый процессор — это не то же самое, что текстовый редактор (Блокнот). Процессор имеет гораздо больше возможностей для форматирования.
✏️ Ввод и редактирование текста
  • Набор текста — ввод символов с клавиатуры
  • Исправление ошибок — удаление, вставка, замена символов
  • Копирование — Ctrl+C → Ctrl+V
  • Вырезание — Ctrl+X → Ctrl+V
  • Отмена действия — Ctrl+Z
  • Повтор действия — Ctrl+Y
🎨 Форматирование символов и абзацев

Форматирование символов:

  • Шрифт (гарнитура): Times New Roman, Arial, Calibri и др.
  • Размер (кегль): измеряется в пунктах (pt)
  • Начертание: жирный (Ctrl+B), курсив (Ctrl+I), подчёркнутый (Ctrl+U)
  • Цвет, регистр, межсимвольный интервал

Форматирование абзацев:

  • Выравнивание: по левому/правому краю, по центру, по ширине
  • Межстрочный интервал: 1.0; 1.5; 2.0 и др.
  • Отступы: первой строки, слева, справа
  • Межабзацные интервалы
  • Маркированные и нумерованные списки
📑 Стили и оглавление

Стиль — это набор параметров форматирования, сохранённый под определённым именем.

Преимущества использования стилей:

  • Единообразие оформления всего документа
  • Быстрое изменение оформления (изменил стиль — изменились все элементы)
  • Автоматическое создание оглавления
  • Навигация по документу через область навигации
⚠️ Внимание: Для автоматического оглавления нужно использовать именно встроенные стили «Заголовок 1», «Заголовок 2» и т.д.
🖼️ Вставка объектов в документ
  • Таблицы — структурированное представление данных
  • Рисунки и фигуры — с возможностью обтекания текстом
  • Диаграммы — визуализация числовых данных
  • Гиперссылки — ссылки на веб-страницы, файлы, якоря
  • Колонтитулы — повторяющиеся элементы в верхней/нижней части страницы
  • Сноски — пояснения внизу страницы или конца документа
  • Символы и формулы — специальные вставки
🔧 Инструменты автоматизации
  • Проверка орфографии — F7, подчёркивание красной волнистой линией
  • Поиск и замена — Ctrl+H, в т.ч. с использованием масок и спецсимволов
  • Слияние (Mail Merge) — массовая рассылка персональных документов
  • Макросы — запись и воспроизведение последовательностей действий
  • Рецензирование — комментарии, исправления, отслеживание изменений
  • Автозамена — автоматическое исправление опечаток и сокращений

🎯 Практический разбор задач (8 задач, 3 уровня)

Нажимайте на кнопки «💡 Подсказка» и «✅ Решение», чтобы раскрыть материалы.

1📜 Оформление стихотворения

Условие: Дан текст стихотворения. Установить шрифт Times New Roman, размер 14; выровнять по центру; межстрочный интервал 1.5; первую строфу — жирным курсивом.

Начните с выделения всего текста (Ctrl+A) — это сэкономит время. Затем перейдите к абзацу и только потом работайте с отдельными строфами.
  1. Ctrl+A → задать шрифт Times New Roman, размер 14.
  2. Вкладка «Главная» → блок «Абзац» → выравнивание по центру, межстрочный интервал 1.5.
  3. Выделить первую строфу мышью → Ctrl+I (курсив), затем Ctrl+B (жирный).
  4. Ctrl+S — сохранить документ.
2🔤 Замена слов в тексте

Условие: В тексте заменить все вхождения слова «компьютер» на «ЭВМ», учитывая разный регистр.

Для массовой замены используйте специальный инструмент, а не ручной поиск. Не забудьте про настройку учёта регистра!
  1. Ctrl+H — открыть окно «Найти и заменить».
  2. В поле «Найти»: компьютер. В поле «Заменить на»: ЭВМ.
  3. Нажать «Больше >>» → установить флажок «Различать регистр» (если нужно учитывать регистр) или снять его (если заменять все).
  4. Нажать «Заменить все».
3📝 Создание маркированного списка

Условие: Преобразовать список пунктов в маркированный список с маркером в виде ромба.

Маркированный список создаётся одной кнопкой на панели «Абзац». Но для выбора конкретного маркера нужно открыть дополнительное меню.
  1. Выделить все пункты списка.
  2. На вкладке «Главная» в блоке «Абзац» нажать на стрелку рядом с кнопкой «Маркеры».
  3. В библиотеке маркеров выбрать ромб (◆).
  4. При необходимости настроить уровень вложенности кнопками «Увеличить/Уменьшить отступ».
4📊 Создание таблицы со стилями

Условие: Вставить таблицу 5×6. Заголовки оформить пользовательским стилем «Заголовок таблицы» (синий фон, белый текст, центрирование). Добавить нижний колонтитул с номером страницы.

Сначала создайте сам стиль, а потом применяйте его. Колонтитулы находятся в отдельном меню «Вставка».
  1. Вставка → Таблица → выбрать 5 строк × 6 столбцов.
  2. Главная → Стили → Создать стиль. Настроить: шрифт — белый, фон — синий, выравнивание — по центру. Сохранить как «Заголовок таблицы».
  3. Выделить первую строку таблицы → применить созданный стиль.
  4. Вставка → Колонтитул → Нижний колонтитул → Номер страницы → В конце раздела.
5🖼️ Вставка рисунка с обтеканием

Условие: Вставить рисунок в документ и настроить обтекание текстом «Сверху и снизу».

По умолчанию рисунок вставляется «В тексте» — он ведёт себя как большой символ. Для обтекания нужно изменить параметр привязки.
  1. Вставка → Рисунки → выбрать файл с изображением.
  2. Щёлкнуть по рисунку правой кнопкой мыши → «Обтекание текстом».
  3. Выбрать вариант «Сверху и снизу».
  4. Переместить рисунок в нужное место — текст автоматически обтекёт его.
6🔗 Создание гиперссылки

Условие: Создать гиперссылку со словом «Источник» на сайт www.example.com, открывающуюся в новой вкладке (в веб-документе).

Гиперссылку можно создать через контекстное меню или специальной кнопкой. Не забудьте про протокол http://.
  1. Написать слово «Источник» и выделить его.
  2. Ctrl+K (или Вставка → Гиперссылка).
  3. В поле «Адрес» ввести: http://www.example.com.
  4. Нажать ОК. Слово станет синим и подчёркнутым.
7📑 Автоматическое оглавление

Условие: В большом отчёте сгенерировать автоматическое оглавление. Заголовки разделов уже оформлены стилями «Заголовок 1» и «Заголовок 2».

Оглавление строится на основе стилей заголовков. Его можно вставить в любое место документа, обычно — в начало.
  1. Поставить курсор в место, где должно быть оглавление (обычно — после титульного листа).
  2. Вкладка «Ссылки» → «Оглавление» → выбрать «Автособираемое оглавление 1».
  3. Оглавление сгенерируется автоматически на основе стилей заголовков.
  4. При изменении текста: правый клик по оглавлению → «Обновить поле» → «Обновить целиком».
8✉️ Слияние данных (Mail Merge)

Условие: Подготовить персональные приглашения для 50 адресатов, используя шаблон письма и базу данных (Excel-файл с именами и адресами).

Слияние — это процесс объединения шаблона документа с источником данных. В шаблон вставляются специальные «поля слияния».
  1. Рассылки → Начать слияния → Письма.
  2. Выбрать получателей → Использовать существующий список → выбрать Excel-файл.
  3. Указать нужный лист и диапазон данных.
  4. Вставить поля слияния: «Вставить поле объединения» → Имя, Адрес и т.д.
  5. «Просмотреть результаты» — проверить корректность.
  6. «Закончить и объединить» → «Печатать документы» или «Изменить отдельные документы».
