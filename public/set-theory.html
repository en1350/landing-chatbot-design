📚 Теория множеств

Интерактивный урок по информатике

📖 Основные понятия

Множество — это совокупность различных объектов, рассматриваемых как единое целое. Объекты, входящие в состав множества, называются его элементами.

Обозначения: множества — заглавными буквами A, B, C, элементы — строчными a, b, c.

Принадлежность элемента множеству: a ∈ A (a принадлежит A).

Способы задания множеств

  • Перечислением: A = {1, 2, 3, 4, 5}
  • Характеристическим свойством: A = {x | x — чётное число, 0 < x < 10}

Виды множеств

  • Конечное — содержит конечное число элементов
  • Бесконечное — содержит бесконечно много элементов
  • Пустое — не содержит ни одного элемента, обозначается ∅
  • Универсальное (U) — содержит все рассматриваемые объекты

Операции над множествами

ОперацияОбозначениеОпределение
ОбъединениеA ∪ B{x | x ∈ A или x ∈ B}
ПересечениеA ∩ B{x | x ∈ A и x ∈ B}
РазностьA \ B{x | x ∈ A и x ∉ B}
Симметрическая разностьA △ B(A \ B) ∪ (B \ A)
ДополнениеĀ (или A'){x | x ∈ U и x ∉ A}

Диаграммы Эйлера-Венна

Свойства операций

  • Коммутативность: A ∪ B = B ∪ A; A ∩ B = B ∩ A
  • Ассоциативность: (A ∪ B) ∪ C = A ∪ (B ∪ C)
  • Дистрибутивность: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
  • Законы де Моргана: A∪B = Ā ∩ B̄; A∩B = Ā ∪ B̄

Мощность множества и формула включений-исключений

Мощность |A| — количество элементов множества A.

|A ∪ B| = |A| + |B| − |A ∩ B|
