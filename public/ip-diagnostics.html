📋 Практическое задание

Тема: Настройка протоколов IP в операционных системах.

Цель: Выполнить диагностику сетевого подключения с помощью командной строки.

  • ◻ Определить собственный IP-адрес и MAC-адрес (физический адрес).
  • ◻ Проверить доступность внешнего ресурса (yandex.ru) с помощью ping.
  • ◻ Построить маршрут следования пакетов с помощью tracert.
💡 Подсказки:
1. Для просмотра настроек сети введите: ipconfig
2. Для проверки доступности: ping yandex.ru
3. Для трассировки маршрута: tracert yandex.ru
4. Очистить экран: cls или clear
5. Используйте стрелки ↑ и ↓ для истории команд.
