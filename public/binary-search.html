🔍 Базовый бинарный поиск (Binary Search)

Алгоритм поиска со сложностью O(log n)

💼 Бизнес-контекст: Быстрый поиск ID пользователя или товара в огромной предварительно отсортированной базе данных.

📚 Архитектура и шаги алгоритма

  • Инициализируйте указатели: left = 0 и right = arr.length - 1.
  • Запустите цикл: while (left <= right).
  • Вычислите средний индекс: mid = Math.floor((left + right) / 2).
  • Если arr[mid] === target, верните mid.
  • Если arr[mid] < target, обновите left = mid + 1.
  • Иначе обновите right = mid - 1.
  • Если цикл завершился, верните -1.

⚠️ Ошибка Junior'а: left < right

Если целевой элемент находится на последней оставшейся позиции (left === right), цикл без равенства не выполнится, и функция вернет -1.

Неправильно:
while (left < right)
Правильно:
while (left <= right)
