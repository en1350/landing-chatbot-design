🎓 Множества: Python vs JavaScript

Интерактивный урок с параллельным сравнением двух языков

📖 Что такое множество?

Множество (set) — неупорядоченная коллекция уникальных элементов. В обоих языках есть встроенная поддержка, но с разной философией.

🐍 Python 
a = {1, 2, 3, 4, 5}
b = set([1, 2, 2, 3])
# b = {1, 2, 3}
# Есть операторы: | & - ^
🟨 JavaScript 
const a = new Set([1, 2, 3, 4, 5]);
const b = new Set([1, 2, 2, 3]);
// b = Set {1, 2, 3}
// Нет операторов — только методы
⚠️ Важно: в Python {} — это пустой словарь, а не множество! Пустое множество: set(). В JavaScript {} — это блок кода или объект.

🔧 Операторы над множествами

Python поддерживает операторы напрямую. В JavaScript нужно использовать методы или комбинации spread и filter.

1. Объединение (Union)

🐍 Python 
a = {1, 2, 3}
b = {3, 4, 5}
c = a | b          # {1, 2, 3, 4, 5}
d = a.union(b)     # то же самое
🟨 JavaScript 
const a = new Set([1, 2, 3]);
const b = new Set([3, 4, 5]);
const c = new Set([...a, ...b]);
// Set {1, 2, 3, 4, 5}

2. Пересечение (Intersection)

🐍 Python 
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
c = a & b          # {3, 4}
d = a.intersection(b)
🟨 JavaScript 
const a = new Set([1, 2, 3, 4]);
const b = new Set([3, 4, 5, 6]);
const c = new Set(
  [...a].filter(x => b.has(x))
);
// Set {3, 4}

3. Разность (Difference)

🐍 Python 
a = {1, 2, 3, 4}
b = {3, 4, 5}
c = a - b          # {1, 2}
d = a.difference(b)
🟨 JavaScript 
const a = new Set([1, 2, 3, 4]);
const b = new Set([3, 4, 5]);
const c = new Set(
  [...a].filter(x => !b.has(x))
);
// Set {1, 2}

4. Симметрическая разность

🐍 Python 
a = {1, 2, 3}
b = {2, 3, 4}
c = a ^ b          # {1, 4}
d = a.symmetric_difference(b)
🟨 JavaScript 
const a = new Set([1, 2, 3]);
const b = new Set([2, 3, 4]);
const c = new Set([
  ...[...a].filter(x => !b.has(x)),
  ...[...b].filter(x => !a.has(x))
]);
// Set {1, 4}

5. Проверка вхождения и подмножества

🐍 Python 
a = {1, 2, 3}
3 in a              # True
{1, 2} <= a         # True (подмножество)
a >= {1, 2}         # True (надмножество)
🟨 JavaScript 
const a = new Set([1, 2, 3]);
a.has(3);           // true
// Подмножество — вручную:
[...b].every(x => a.has(x));
