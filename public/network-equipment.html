📚 Теоретический блок

Коммуникационное оборудование — это устройства, обеспечивающие передачу данных между узлами компьютерной сети. Рассмотрим основные из них.

🔀

Концентратор (Hub)

Простейшее устройство. Рассылает сигнал всем портам. Работает на физическом уровне. Устарел.

🔌

Коммутатор (Switch)

Передаёт кадры только адресату по MAC-адресу. Работает на канальном уровне (L2).

🌍

Маршрутизатор (Router)

Соединяет разные сети, маршрутизирует пакеты по IP. Работает на сетевом уровне (L3).

📡

Точка доступа (AP)

Обеспечивает беспроводное подключение клиентов по Wi-Fi к проводной сети.

🛡️

Межсетевой экран (Firewall)

Фильтрует трафик по заданным правилам. Обеспечивает безопасность сети.

📦

Модель OSI (7 уровней)

Физический → Канальный → Сетевой → Транспортный → Сеансовый → Представительный → Прикладной

💡 Запомните

Hub — "кричит" всем. Switch — шепчет адресату. Router — знает дорогу между сетями.
