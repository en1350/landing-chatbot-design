📚 Что такое хеш-таблица?

Хеш-таблица (Hash Table) — это структура данных, которая хранит пары «ключ-значение» и обеспечивает сверхбыстрый доступ к данным (в среднем за O(1)).

💡 Аналогия из жизни: Гардероб
Вы сдаете куртку (это значение). Вам дают номерок (это ключ). Гардеробщик не ищет вашу куртку перебором всех вешалок. Он смотрит на номерок, применяет простое правило (например, "номер 45 -> стеллаж 4, крючок 5") и мгновенно находит вашу вещь. Это правило и есть хеш-функция.

Как это работает (3 шага):

  1. Хеширование: Ключ (например, строка "apple") преобразуется хеш-функцией в число (хеш-код).
  2. Индексация: Хеш-код делится по модулю на размер массива (`hash % size`), чтобы получить индекс ячейки (бакета).
  3. Сохранение: Значение помещается в ячейку с этим индексом. Если ячейка занята, возникает коллизия, которая решается методами цепочек (список в ячейке) или открытой адресации.

Реализация в языках программирования:

# Python: Словарь (dict)
my_dict = {"name": "Алексей", "age": 25}
print(my_dict["name"]) # Вывод: Алексей
// JavaScript: Объект или Map
const myMap = new Map();
myMap.set("name", "Алексей");
console.log(myMap.get("name")); // Вывод: Алексей

💻 Практические примеры и разбор

Рассмотрим реальную задачу: Подсчет частоты слов в тексте. Это классическое применение хеш-таблиц.

Реализация на Python

def count_words(text):
    word_counts = {} # Создаем пустую хеш-таблицу
    for word in text.split():
        if word in word_counts:
            word_counts[word] += 1 # O(1) доступ!
        else:
            word_counts[word] = 1
    return word_counts

print(count_words("яблоко банан яблоко"))
# Вывод: {'яблоко': 2, 'банан': 1}

Реализация на JavaScript

function countWords(text) {
    const wordCounts = new Map(); // Создаем хеш-таблицу
    const words = text.split(' ');

    for (const word of words) {
        if (wordCounts.has(word)) {
            wordCounts.set(word, wordCounts.get(word) + 1); // O(1) доступ!
        } else {
            wordCounts.set(word, 1);
        }
    }
    return wordCounts;
}

console.log(countWords("яблоко банан яблоко"));
// Вывод: Map(2) { 'яблоко' => 2, 'банан' => 1 }

🔍 Разбор сложности:

  • Вставка (Insert): O(1) в среднем случае.
  • Поиск (Get): O(1) в среднем случае.
  • Худший случай: O(n), если все ключи дают одинаковый хеш (коллизия), превращая таблицу в связный список. Хорошая хеш-функция минимизирует этот риск.
