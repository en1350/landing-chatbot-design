Формулы расчёта

Качество знаний (КЗ): КЗ = (n₄ + n₅) / N × 100%

Успеваемость (У): У = (N − n₂) / N × 100%

Средний балл (СО): СО = (2·n₂ + 3·n₃ + 4·n₄ + 5·n₅) / N

Прирост КЗ (Δ): Δ = КЗ(окончание) − КЗ(начало)
