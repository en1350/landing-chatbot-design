📚 Теория: Программы линейной структуры

Что такое линейная структура?

Линейная структура — это простейшая алгоритмическая конструкция, в которой команды выполняются последовательно, одна за другой, в том порядке, в котором они записаны.

Основные характеристики:

  • Команды выполняются строго по порядку
  • Нет условных переходов (if/else)
  • Нет циклов (for, while)
  • Каждая команда выполняется ровно один раз

Базовые операции:

  1. Ввод данных — получение информации от пользователя
  2. Обработка данных — вычисления и преобразования
  3. Вывод результатов — отображение информации

Пример: Вычисление площади прямоугольника

🐍 Python

# Ввод данных
length = float(input("Введите длину: "))
width = float(input("Введите ширину: "))

# Обработка (вычисление)
area = length * width

# Вывод результата
print(f"Площадь прямоугольника: {area}")

⚡ JavaScript

// Ввод данных
let length = parseFloat(prompt("Введите длину: "));
let width = parseFloat(prompt("Введите ширину: "));

// Обработка (вычисление)
let area = length * width;

// Вывод результата
console.log(`Площадь прямоугольника: ${area}`);
alert(`Площадь прямоугольника: ${area}`);

Арифметические операции:

  • + — сложение
  • - — вычитание
  • * — умножение
  • / — деление
  • ** или Math.pow() — возведение в степень
  • % — остаток от деления

Математические функции:

🐍 Python

import math

# Квадратный корень
sqrt_x = math.sqrt(x)

# Абсолютное значение
abs_x = abs(x)

# Округление
rounded = round(x, 2)

# Степень
power = x ** 2

⚡ JavaScript

// Квадратный корень
let sqrtX = Math.sqrt(x);

// Абсолютное значение
let absX = Math.abs(x);

// Округление
let rounded = x.toFixed(2);

// Степень
let power = Math.pow(x, 2);
