📖 Что нужно знать?

🔢 Что такое последовательность?

Последовательность — это просто набор чисел, записанных в ряд. Например: 42, 7, 63, 21, 100

Каждое число в последовательности имеет свой номер (позицию): первое, второе, третье и т.д.

👫 Что такое пара?

Пара — это два числа, которые стоят рядом (подряд) в последовательности.

В последовательности 42, 7, 63, 21, 100 есть такие пары:

  • (42, 7) — первое и второе числа
  • (7, 63) — второе и третье числа
  • (63, 21) — третье и четвёртое числа
  • (21, 100) — четвёртое и пятое числа

👉 Если в последовательности N чисел, то пар будет N−1.

➗ Что значит «делится на»?

Число A делится на число B, если при делении A на B получается целое число без остатка.

Примеры:

  • ✅ 42 делится на 21, потому что 42 ÷ 21 = 2 (целое!)
  • ✅ 63 делится на 21, потому что 63 ÷ 21 = 3
  • ❌ 100 не делится на 21, потому что 100 ÷ 21 = 4.76... (не целое)

🎯 На языке программирования: A % B == 0 (остаток от деления равен нулю).

🎯 Что такое «кратное 21»?

Число кратно 21, если оно делится на 21 без остатка.

Примеры чисел, кратных 21: 21, 42, 63, 84, 105, 126, ...

Проверка: число кратно 21, если число % 21 == 0

📝 Условие задачи простыми словами

Дана последовательность чисел. Нужно:

  1. Найти среди всех чисел самое маленькое, которое делится на 21.
  2. Посмотреть на все пары соседних чисел.
  3. Для каждой пары проверить: делится ли хотя бы одно из двух чисел на найденное число из пункта 1.
  4. Посчитать, сколько таких пар нашлось.
  5. Найти максимальную сумму среди этих пар.

🧠 Алгоритм решения

Шаг 1

Прочитать все числа

Загружаем последовательность чисел в память (например, в список или массив).

Шаг 2

Найти минимальное число, кратное 21

Заводим переменную min21 = очень большое число. Проходим по всем числам:

  • Если число делится на 21 (число % 21 == 0) и оно меньше min21, то запоминаем его как min21.

В конце min21 будет содержать искомое число.

Шаг 3

Пройти по всем парам подряд идущих чисел

Цикл от первого до предпоследнего элемента. На каждом шаге берём пару: текущее число и следующее.

Шаг 4

Проверить пару

Для пары (a, b) проверяем условие:

a % min21 == 0 ИЛИ b % min21 == 0

Если условие выполнено — пара нам подходит!

Шаг 5

Считать и запомнить

  • Увеличиваем счётчик подходящих пар на 1.
  • Считаем сумму элементов пары: sum = a + b.
  • Если сумма больше текущего максимума — запоминаем её.
Шаг 6

Вывести результат

После проверки всех пар выводим:

  • Количество подходящих пар
  • Максимальную сумму среди них

💻 Пример кода на Python

# Читаем числа
a = [42, 7, 63, 21, 100]

# Шаг 1: ищем min21
min21 = 100001
for x in a:
    if x % 21 == 0 and x < min21:
        min21 = x

# Шаг 2: проходим по парам
count = 0
max_sum = 0
for i in range(len(a) - 1):
    if a[i] % min21 == 0 or a[i+1] % min21 == 0:
        count += 1
        s = a[i] + a[i+1]
        if s > max_sum:
            max_sum = s

print(count, max_sum)
