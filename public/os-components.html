🖥️ Функциональные компоненты ОС

Интерактивный урок с теорией, тестом и персональным сертификатом

📚 Введение

Операционная система (ОС) — это комплекс взаимосвязанных программ, которые управляют аппаратными ресурсами компьютера и предоставляют среду для выполнения прикладных программ.

💡 Примеры ОС: Windows, Linux, macOS, Android, iOS

Основные функции ОС:

  • Управление процессами
  • Управление памятью
  • Управление файловой системой
  • Управление устройствами ввода-вывода
  • Предоставление пользовательского интерфейса
  • Обеспечение безопасности

⚙️ 1. Ядро операционной системы

Ядро (kernel) — центральная часть ОС, работающая в привилегированном режиме (режим ядра). Оно обеспечивает взаимодействие между аппаратным обеспечением и программным.

Типы ядер:

ТипОписаниеПример
МонолитноеВсе функции в одном модулеLinux, классический UNIX
МикроядроМинимум функций в ядреMinix, QNX
ГибридноеКомбинация подходовWindows NT, macOS XNU
🔧 Задачи ядра: управление процессами, памятью, прерываниями, системными вызовами.

🔄 2. Управление процессами

Процесс — выполняющаяся программа вместе с её окружением (память, ресурсы, состояние).

Состояния процесса:

  1. Новый — создан, но ещё не запущен
  2. Готов — ожидает выделения процессора
  3. Выполняется — работает на CPU
  4. Ожидание — ждёт события (ввод/вывод)
  5. Завершён — выполнение окончено
⚠️ Планировщик — компонент ОС, определяющий, какой процесс получит процессор в каждый момент времени. Алгоритмы: FIFO, Round Robin, приоритетный.

💾 3. Управление памятью

Менеджер памяти распределяет оперативную память между процессами и обеспечивает их изоляцию.

Основные методы:

  • Разбиение на разделы — память делится на фиксированные/динамические блоки
  • Страничная организация — память делится на страницы (обычно 4 КБ)
  • Сегментная организация — память делится на логические сегменты
  • Виртуальная память — использование диска как расширения ОЗУ
📌 Свойства виртуальной памяти: позволяет запускать программы, размер которых превышает объём физической памяти, за счёт подкачки страниц с диска.

📁 4. Файловая система

Файловая система — способ организации, хранения и именования файлов на дисках.

Популярные файловые системы:

  • NTFS — используется в Windows
  • ext4 / btrfs — используются в Linux
  • APFS — используется в macOS
  • FAT32 / exFAT — для флеш-накопителей

Операции с файлами:

создание, чтение, запись, удаление, переименование, поиск, установка атрибутов (только чтение, скрытый, системный).

🖨️ 5. Управление устройствами ввода-вывода

ОС обеспечивает единый интерфейс работы с разнообразными устройствами через драйверы.

Драйвер устройства

— это специальная программа, которая «знает», как взаимодействовать с конкретным устройством (принтером, видеокартой, сетевой картой).

Методы ввода-вывода:

  • Программный ввод-вывод — процессор непосредственно управляет устройством
  • Прерывания — устройство сигнализирует о готовности
  • Прямой доступ к памяти (ПДП/DMA) — устройство обменивается данными с памятью без участия CPU

🖱️ 6. Пользовательский интерфейс

ОС предоставляет пользователю способы взаимодействия с компьютером.

Типы интерфейсов:

  • CLI (Command Line Interface) — командная строка: ls, cd, dir
  • GUI (Graphical User Interface) — графический интерфейс с окнами, иконками, меню
  • TUI (Text User Interface) — текстовые меню (например, BIOS)
🌟 Оболочки: в Linux — bash, zsh; в Windows — cmd, PowerShell.

🔒 7. Безопасность и защита

ОС обеспечивает защиту данных и ресурсов от несанкционированного доступа.

Механизмы защиты:

  • Аутентификация — проверка личности (пароль, биометрия)
  • Авторизация — определение прав доступа
  • Изоляция процессов — каждый процесс имеет своё адресное пространство
  • Шифрование — защита данных на диске и в сети
  • Журналирование — запись действий пользователей
